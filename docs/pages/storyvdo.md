## ภาพรวมของระบบ (Overview)

**Tora StoryVDO** เป็นแพลตฟอร์มผลิตละครสั้นและมังงะวิดีโอ AI อัตโนมัติ ที่ช่วยเปลี่ยนพล็อตเรื่องสั้นเพียง 2-3 บรรทัด ให้กลายเป็นซีรีส์ละครระดับโปรดักชันได้ในคลิกเดียว:
- **AI Script Rewriter**: ขยายพล็อตย่อเป็นบทละครโทรทัศน์มาตรฐานภาษาไทย แยกฉาก อารมณ์ แอ็กชัน และบทพูด
- **Face Consistency LCK**: สกัดตัวละครและสร้าง Character Reference Sheet แบบ 3 มุมมองเพื่อล็อกหน้าตาและเสื้อผ้า
- **Multi-Video Models**: รองรับโมเดลสร้างวิดีโอชั้นนำทั้ง Google Flow Veo 2, Seedance 2.0, Wan 2.2, และ MiniMax H3
- **Zero-Install SQLite & FFmpeg**: มีระบบฐานข้อมูลและเครื่องยนต์ตัดต่อในตัว ประมวลผลและรวมคลิปทั้งตอนอัตโนมัติ

```text
1. สมัคร Tora Token ➔ 2. สร้างโปรเจกต์ ➔ 3. AI เขียนบท ➔ 4. สกัดสินทรัพย์ ➔ 5. เจนวิดีโอ ➔ 6. รวมคลิป
```

## ส่วนที่ 1: การติดตั้งและการเชื่อมต่อ (Setup & Overview)

### 1.1 สมัครและออก Token จาก toraapi.com
ระบบ StoryVDO ใช้ **Tora API (toraapi.com)** เป็นตัวกลางจัดการเครดิตแบบจ่ายตามจริง ช่วยให้คุณใช้ API Key เดียวเชื่อมต่อโมเดล AI ชั้นนำได้ครบทุกค่าย:
1. เข้าสู่เว็บไซต์ [toraapi.com](https://toraapi.com) และเข้าสู่ระบบ
2. ไปที่เมนู **"โทเค็น" (API Keys)**
3. กดปุ่ม **"สร้างโทเค็นใหม่"** ตั้งชื่อ และคัดลอกรหัส `sk-...`
4. นำรหัสไปใส่ในหน้าต่างตั้งค่าของ StoryVDO

![ภาพที่ 1.1: หน้าต่างกรอก Tora API Key บนระบบ Tora StoryVDO](/images/storyvdo/02-tora-login-modal.png)

### 1.2 ตั้งค่า AI Services & Google Flow ฟรี
คลิกเมนู **"ตั้งค่า" (Settings)** ในระบบ StoryVDO เพื่อตรวจสอบสถานะการเชื่อมต่อ:
- **Tora API Bridge**: แสดงเครดิตคงเหลือและสถานะโควตาแบบเรียลไทม์
- **Google Flow Bridge**: เชื่อมต่อกับบัญชี Google เพื่อดึงเครดิตฟรีมาใช้สร้างภาพ (Imagen 3) และวิดีโอ (Veo 2) ได้ทันทีโดยไม่ต้องเสียค่า API Key

![ภาพที่ 1.2: ตรวจสอบสถานะบัญชีและเครดิตคงเหลือในหน้า Settings](/images/storyvdo/01-settings-page.png)

## ส่วนที่ 2: สร้างโปรเจกต์และ AI เขียนบท (Project & Script)

### 2.1 สร้างโปรเจกต์ & เลือกสไตล์ภาพยนตร์
กำหนดทิศทางภาพและสัดส่วนของซีรีส์ โดยสไตล์ที่เลือกจะถูกฝังเป็นแกนกลางของ Prompt ทุกรูปและทุกคลิป:
- **อัตราส่วน (Aspect Ratio)**:
  - `9:16` สำหรับแนวตั้งมือถือ (TikTok, Reels, Shorts)
  - `16:9` สำหรับแนวนอนภาพยนตร์ (YouTube, TV)
- **สไตล์ภาพ (Art Style)**: เช่น *ภาพยนตร์คนจริงสมจริง 35mm/IMAX Cinematic*, *3D Animation*, หรือ *Anime*

![ภาพที่ 2.1: หน้าต่างสร้างโปรเจกต์และกำหนดสไตล์ภาพ](/images/storyvdo/04-create-project-modal.png)

### 2.2 จัดการตอน & เข้าสู่สตูดิโอผลิต (Episode Studio)
ในหน้ารายการตอน คุณสามารถดูสถานะ ความยาว ความละเอียด และคลิก **"เปิดสตูดิโอ"** เพื่อเข้าสู่หน้าทำงานครบวงจรที่รวม: บทละคร ➔ แอสเซท ➔ วิดีโอสตอรี่บอร์ด ➔ ส่งออก ไว้ในหน้าจอเดียว

![ภาพที่ 2.2: หน้ารายการตอนและปุ่มเปิดสตูดิโอทำงาน](/images/storyvdo/05-episodes-list.png)

### 2.3 ป้อนพล็อตสั้น ➔ ให้ AI Rewrite เจนบทถ่ายทำเต็ม
คุณไม่จำเป็นต้องพิมพ์บทยาวด้วยตัวเอง เพียงป้อนเรื่องย่อ 2-3 บรรทัด แล้วกดปุ่ม **"เริ่มเขียนบท"**:
- AI Agent จะแยกบทเป็นฉากมาตรฐาน (S01, S02...)
- กำหนดชื่อตัวละคร อารมณ์ แอ็กชัน และบทสนทนาภาษาไทยอย่างเป็นธรรมชาติ
- ให้ผลลัพธ์บทละครมาตรฐาน 2,000–3,000+ ตัวอักษรพร้อมนำไปสร้างสตอรี่บอร์ดทันที

![ภาพที่ 2.3: ป้อนพล็อตสั้นๆ ในแท็บเนื้อหาต้นฉบับ](/images/storyvdo/06-script-stage.png)

![ภาพที่ 2.4: ผลลัพธ์บทละครมาตรฐานพร้อมถ่ายทำ](/images/storyvdo/07-script-rewritten.png)

## ส่วนที่ 3: สกัดสินทรัพย์และผลิตวิดีโอสตอรี่บอร์ด (Assets & Video)

### 3.1 สกัดสินทรัพย์ & Character Turnaround เพื่อล็อกหน้า
คลิกปุ่ม **"สกัดตัวละคร / ฉาก / อุปกรณ์"** ระบบจะตรวจจับสิ่งที่ต้องใช้ในบทละครออกมาให้อัตโนมัติ:
- สร้าง **Character Reference Sheet** แบบ 3 มุมมอง (หน้าตรง, ด้านข้าง 90 องศา, ด้านหลัง)
- ล็อกโครงหน้า สีผม เครื่องแต่งกาย ให้ตัวละครมีความคงเส้นคงวา (Consistency) ตลอดทั้งตอน
- สามารถอัปโหลดภาพบุคคลจริง หรือภาพจากเครื่องมือภายนอกมาใช้เป็น Master Face ได้

![ภาพที่ 3.1: หน้าคลังสินทรัพย์ พร้อมปุ่มส่ง Reference ไป Google Flow และปุ่มอัปโหลดรูปภาพ](/images/storyvdo/08-assets-stage.png)

### 3.2 แตกสตอรี่บอร์ดและสั่งเรนเดอร์วิดีโอ
ในแท็บ **"การผลิตวิดีโอ"** ระบบจะแตกบทออกเป็นมุมกล้องรายช็อต พร้อมระบุความยาว (5s / 10s) และแนบแท็ก `@Character` ให้ตรงกับตัวละครในฉาก:
- **เมนูเลือกโมเดลวิดีโอ (แถบด้านบน)**: สลับโมเดลได้อิสระตามความเหมาะสมของฉาก:
  - **Google Flow Veo 2**: ฟรีเครดิต คุณภาพสูง คมชัด ลื่นไหล
  - **Seedance 2.0**: สไตล์ภาพยนตร์สมจริง การเคลื่อนไหวมีมิติตามกฎฟิสิกส์
  - **Wan 2.2 / MiniMax H3**: อารมณ์ตัวละครและการแสดงสีหน้ายอดเยี่ยม
- คลิก **"สร้างวิดีโอทั้งหมด"** เพื่อเรนเดอร์ทั้งซีรีส์ในคลิกเดียว หรือกด **"สร้างใหม่"** เฉพาะช็อตที่ต้องการปรับแต่ง

![ภาพที่ 3.2: หน้าจอสตอรี่บอร์ดพร้อม Dropdown สลับโมเดลวิดีโอด้านบน](/images/storyvdo/09-storyboard-videos.png)

## ส่วนที่ 4: รวมคลิปและเคล็ดลับขั้นเซียน (Export & Pro Tips)

### 4.1 ตรวจสอบไทม์ไลน์และรวมคลิปด้วย FFmpeg
ในแท็บ **"รวมวิดีโอและส่งออก"**:
1. พรีวิวคลิปแต่ละช็อตบนไทม์ไลน์
2. ปรับลำดับ ตัดต่อ หรือเปลี่ยนเฉพาะคลิปที่ต้องการ
3. กดปุ่ม **"รวมวิดีโอที่เลือก"**: เครื่องยนต์ FFmpeg ภายในระบบจะปรับขนาดความละเอียด เฟรมเรต และเชื่อมต่อทุกคลิปเข้าด้วยกันเป็นไฟล์ `.mp4` พร้อมเสียงประกอบและซับไตเติลอย่างสมบูรณ์แบบ
4. กด **"ดาวน์โหลด"** เพื่อนำไฟล์วิดีโอไปเผยแพร่ได้ทันที

![ภาพที่ 4.1: หน้าต่างรวมคลิปทั้งตอน มีปุ่มดาวน์โหลด และปุ่มนำเข้า/เปลี่ยนวิดีโอ](/images/storyvdo/10-export-merge.png)

---

### 4.2 เคล็ดลับขั้นเซียน: ล็อกตัวละครให้นิ่ง 100% & ประหยัดเครดิต API

หากคุณต้องการคุมหน้าตาตัวละครให้เป๊ะตามใจสั่ง 100% หรือต้องการประหยัดค่าใช้จ่าย API ให้ใช้เทคนิค **Manual Hybrid Workflow**:

> [!IMPORTANT]
> 1. **คัดลอก Prompt ไปสร้างรูปข้างนอก**:
>    คัดลอก Prompt ตัวละครจากแท็บ Assets ไปเจนใน **Midjourney, Fooocus หรือ ComfyUI** แล้วกดปุ่ม **"อัปโหลด"** ที่การ์ดตัวละครเพื่อนำรูปกลับเข้ามาแทนที่ ใบหน้าและชุดจะนิ่งสนิท 100%
>
> 2. **เจนวิดีโอภายนอกแล้วนำเข้า**:
>    สำหรับช็อตสำคัญ สามารถนำ Prompt และภาพอ้างอิงไปสร้างในแพลตฟอร์มภายนอกที่มีบุฟเฟต์ แล้วกดปุ่ม **"เปลี่ยนวิดีโอ / นำเข้าวิดีโอ"** ในหน้า Export เพื่อให้ FFmpeg ช่วยรวมคลิปให้โดยไม่เสียเครดิตเพิ่ม!
>
> **สรุปสูตรประหยัด**: ใช้ Tora StoryVDO คิดบท + แบ่งช็อต + ต่อคลิป | ใช้ AI ภายนอกคุมหน้าตา = **ประหยัดเงิน & ผลงานเป๊ะ 100%**
